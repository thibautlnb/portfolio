Projet 1.4 — Se présenter sur Internet

1Description & Objectif

Création complète d'un site internet personnel multi-pages, dynamique et responsive, sur le thème de la musculation. L'objectif était de maîtriser les bases du développement front-end (HTML sémantique, CSS Flexbox, responsive design, animations CSS) et de livrer un site fonctionnel hébergé sur GitHub Pages.

Fonctionnalités techniques implémentées
Responsive Design CSS Media Queries

Adaptation du layout pour mobile, tablette et desktop via @media (max-width: 768px). Navigation en colonne sur mobile, images redimensionnées.

Carrousel CSS pur Sans JavaScript

Slider Push/Pull/Legs implémenté uniquement avec des input[type=radio] et des sélecteurs CSS adjacents. Flèches de navigation et points actifs inclus.

Animations au survol CSS Transitions

Animation scale(1.1) sur les images d'accueil, effet "blob" radial sur les boutons de navigation par transform: scale3d().

Charte graphique multi-page CSS Variables

Chaque page possède sa propre couleur d'accent (rouge, bleu, violet, vert, orange) via linear-gradient en fond et CSS dédié par fichier.

Mise en page Flexbox CSS Layout

Structure entière basée sur display: flex pour l'en-tête, les sections de contenu, et les grilles d'articles. Aucun framework CSS utilisé.

Hébergement GitHub Pages Déploiement

Dépôt Git public, déploiement automatique sur thibautlnb.github.io/site-internet/. Gestion des commits avec messages porteurs de sens.

4Autoévaluation & Réflexion

Ce que j'ai appris

J'ai appris les fondamentaux du HTML sémantique et du CSS : structuration des balises (<header>, <main>, <section>), modèle de boîte, mise en page par Flexbox et positionnement. J'ai compris l'importance du responsive design avec les media queries. J'ai également découvert qu'il est possible de créer des interactions complexes (comme un carrousel) uniquement en CSS, sans JavaScript, grâce aux sélecteurs adjacents sur les input[type=radio]. Enfin, j'ai pris en main Git et GitHub Pages pour versionner et héberger mon code.

⚠Difficultés rencontrées ✓Solutions apportées
#01 Réaliser un carrousel interactif sans JavaScript. Les approches classiques demandent du JS, mais le cahier des charges se limitait à HTML/CSS. #01 Utilisation de input[type="radio"] invisibles et de sélecteurs CSS adjacents (:checked ~ .track) pour piloter le translateX de la piste, créant un carrousel entièrement CSS avec flèches et points de navigation.
#02 Maintenir une cohérence visuelle entre 5 pages ayant chacune leur propre couleur dominante, tout en partageant la même structure de navigation. #02 Attribution d'un fichier CSS dédié à chaque page (style.css, pratique.css, etc.) pour les couleurs spécifiques, tout en dupliquant les règles communes (header, nav, footer, boutons) dans chaque feuille afin de maintenir la cohérence.
